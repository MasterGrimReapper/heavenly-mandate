# Windows (desktop)

The Windows desktop version is **not** an APK: the `.apk` in [`android/`](../android/README.md) only runs on Android.

**Download:** when a Windows build is published, it is attached to the newest entry on the [Releases page](https://github.com/MasterGrimReapper/heavenly-mandate/releases) as `HeavenlyMandate-Windows-<version>.zip` (about 150 MB; GitHub only allows files that large on Releases).

**Install (portable, nothing to set up):**
1. Download the zip and extract it anywhere (right-click › Extract All).
2. Open the `Heavenly Mandate` folder and run **HeavenlyMandate.exe**.
3. Windows SmartScreen may say it doesn't recognise the app, because the build isn't code-signed yet. Choose **More info › Run anyway**.

Needs 64-bit Windows 10 or 11 and a graphics card from the last several years. Your progress and settings are kept in `%APPDATA%\Heavenly Mandate`.

A Steam release is planned; the Steam version will update itself through Steam.
