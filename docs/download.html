Installing the APK

Until the game is on Google Play, install it straight from this site. It takes about a minute.

  1. Download the APK on your Android phone or tablet with the button above. You need Android 8 or newer and about 32 MB of space.
  2. Open the file from the download notification, or from the Downloads folder in your file manager.
  3. Allow installing from your browser if Android asks: tap Settings, turn on “Allow from this source”, then go back.
  4. Tap Install, then Open. The first lesson starts on its own; you can skip it if you know MOBAs.
  5. Updates are automatic. When a new version is out, the game asks you to update; tap Update. Your progress stays.
