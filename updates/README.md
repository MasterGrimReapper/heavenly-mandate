# updates/ (used by the Android app)

This folder is read by the **Android app** each time it starts. `update.json` says which version is newest and where to download it. Players don't need anything here.

- To download the game for Android, use [`android/HeavenlyMandate-Android.apk`](../android/HeavenlyMandate-Android.apk).
- The Windows desktop version is not hosted here; see [`windows/`](../windows/README.md).
