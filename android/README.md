# Android

**[HeavenlyMandate-Android.apk](HeavenlyMandate-Android.apk)**: the Android app (phones and tablets, Android 7.0 or newer).

1. Download the APK on your phone.
2. Open it from your Downloads. The first time, Android asks you to allow installing apps from that source: allow it, go back and tap **Install**.
3. After that, the app checks for updates every time it starts and installs them from inside the game.

This file is only for Android. It does not run on Windows, Mac or iPhone.
